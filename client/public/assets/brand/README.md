# Kit de marca — Vértice Invest

Os arquivos deste diretório formam o sistema de logo responsivo da aplicação. Todos os derivados atuais preservam o desenho, as cores e o degradê da arte original.

## Uso recomendado

- `vertice-symbol-transparent.png`: arquivo original, sem alterações.
- `vertice-symbol-ui.png`: recorte técnico da mesma arte para cabeçalhos e espaços de 24–64 px.
- `vertice-icon-16.png`, `32`, `48`, `180`, `192` e `512`: navegadores e atalhos de dispositivos.
- `vertice-icon-512-maskable.png`: ícone PWA com zona segura para recortes do sistema operacional.

## Regras rápidas

- Use o arquivo original a partir de 80 px; abaixo disso, prefira o recorte `ui`.
- Não distorça, gire, remova detalhes nem altere o degradê.
- Preserve uma área livre mínima equivalente a 15% da largura do símbolo.
- O nome “Vértice” ao lado da marca deve permanecer como texto HTML para acessibilidade e nitidez.

## Cores

- Os tons do símbolo vêm da arte original e não devem ser recoloridos.
- Fundo institucional dos ícones: `#0F141A`.
